怎么给别人的 AI 用
================================================

一、你只需要做两件事
------------------------------------------------

第 1 件：把压缩包发给他，他解压（解压到哪都行，桌面、下载、U 盘都行）

第 2 件：把那个文件夹的路径给他，加上一句话

    路径怎么拿（挑一种最省事的）：
      · 右键解压出来的文件夹 → 复制文件地址 / 复制为路径
      · 直接把文件夹拖进对话框（多数 AI 客户端支持拖拽）
      · 或者说"在我桌面上，叫中国医疗器械法规库"，让它自己找

    话怎么说（原话就行）：

      "这是法规库技能，在 <解压到哪都行>\china-medical-device-regs，
       帮我装上，然后更新一次"

    ★ 关键是路径要指到「里面有 SKILL.md 的那一层」。
      这个文件夹叫什么，取决于从哪儿拿的：
        · 从 GitHub 下载解压 → china-medical-device-regs-main
        · 从网盘或别人发来的压缩包 → 中国医械法规库技能包\china-medical-device-regs
      外面那层包装不用管，认准里面有 SKILL.md 就对了。
      拿不准就直接把那个文件夹拖进对话框，比手打路径省事。

    关键是两句话：
      一句告诉他「这是法规库技能 + 文件夹在哪」
      一句告诉他「装上」和「更新一次」

    ★ 不想装也行：文件夹放原地别动，直接说
      "在这个文件夹里跑 python run.py"，
      效果完全一样。装进技能目录的唯一好处是
      以后说"更新法规库"他就能自己想起来。


二、他的 AI 接下来会自动做这些
------------------------------------------------
  · 按你给的路径读 SKILL.md，看懂这是个什么技能
  · 搞清楚自己平台的技能目录在哪（每个平台不一样，由它自己探）
  · 把文件夹整个复制进技能目录，验证装上没
  · 跑 python run.py —— 缺的环境它自己下自己装
  · 抓官方最新法规 → 生成页面 → 告诉你文件在哪

你不用教他 skills 路径。他真找不到，会反过来问你"你的工作目录在哪"。


三、就算他不装，也能直接用
------------------------------------------------
不装只是少了"以后说一句'更新法规库'就能自动想起来"这个便利，
其它一模一样。

直接让他对 AI 说：
     "在 <那个文件夹的路径> 里跑 python run.py"


四、如果他那边是网页版 AI（不能跑本地程序）
------------------------------------------------
网页版 AI 装不了技能，也跑不了脚本，只能他自己双击 启动.bat。
或者把 SKILL.md 的内容发给 AI，让它一步步指导他操作。


五、怎么判断他那边弄成了
------------------------------------------------
最省事的一问：

     "你那个法规库技能，是干什么的？"

AI 能说出"抓国家药监局、器审中心，以及十几个省级药监局的法规，
生成一个单文件网页"——就是装上了。

或者看他干活时有没有提到 run.py / check_env.py 这些名字。


六、如果他根本不用 AI
------------------------------------------------
不需要装任何东西。
双击文件夹里的 启动.bat，环境、抓取、生成页面全自动。


七、他那边需要什么（就这些）
------------------------------------------------
  · 一个 Python，3.9 以上
  · 能上网

  依赖只有一条：
    pip install "scrapling[fetchers]"

  它会连浏览器内核一起装。

  他电脑上要是连 Python 都没有——Windows 让他双击
  启动.bat，会自动下一个便携版（11MB），不用自己装。
  Mac / Linux 得自己装 Python。

八、以后要更新到最新版怎么办
------------------------------------------------
不用卸载重装，也不用他自己去下载、解压、拷文件夹。
升级就是「再装一次」，默认覆盖原来那份，他抓的数据和已经生成
的网页都不会丢。

两种办法，哪种顺手用哪种。

【办法一】给他地址，让他的 AI 自己上网拉

  他对自己的 AI 说（原话就行）：

    "帮我更新「中国医械法规库」技能到最新版，地址是
     https://github.com/Alynxiao/china-medical-device-regs 。
     我原来那份就装在本机（文件夹叫 中国医械法规库技能包 或
     china-medical-device-regs，你找一下），把新版覆盖上去。
     装完跑一次更新，然后告诉我页面顶部的版本号。"

【办法二】把 zip 文件发给他，由他的 AI 装
       （他那边上不了网时用这个）

  他对自己说：

    "我这儿有个「中国医械法规库」的新版压缩包（就是刚发来的那个
     文件，路径是 ____）。我原来那份装在本机（文件夹叫
     中国医械法规库技能包 或 china-medical-device-regs，你找一下），
     用它覆盖上去。装完跑一次更新，然后告诉我页面顶部的版本号。"

  这个办法全程不上网，只认本地那个 zip；zip 里目录套几层都能认出来。

两个办法用的是同一个安装脚本、同一套保护：

  · 只替换程序、说明、配置、图片这些文件
  · 他抓来的通报记录（logs 文件夹）原样不动
  · 已经生成的历史网页（.html）不删不盖
  · 法规数据只往里补新条目，不整份覆盖
  · 覆盖前先把旧文件备份进 _backup 文件夹，只留最近 3 次
  · 中途任何一步出错，一个文件都不改，原样留着

他要做的只有一件事：把上面那两句里的一句交给 AI。
不用敲命令，不用管文件夹结构，也不用自己替换文件。
